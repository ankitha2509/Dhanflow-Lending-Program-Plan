# SteerPlan — Lending Program Milestone & Stakeholder Tracker

## Overview
Program planning project simulating how a PM intern 
tracks milestones, manages stakeholders and monitors 
risks for a digital lending feature launch.

## Tools Used
- Excel — Milestone tracker, Stakeholder map, 
  Risk register and Dashboard

## Project Structure
- /excel-plan — Full program plan workbook

## Sheets Inside
- Milestone Tracker — 12 milestones across 4 phases
- Stakeholder Map — 8 stakeholders with communication plan
- Risk Register — 8 risks with mitigation plans
- Dashboard — KPI cards and 4 visual charts
